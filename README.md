# QWEN

A premium, responsive landing page built as a visual foundation for the QWEN project.

## Stack

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- Google Fonts: Space Grotesk + DM Sans
- No build step or framework required

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy

The project is ready for GitHub Pages, Vercel, Netlify, or any static hosting provider.
